🎨 FITUR DETAIL BREAKDOWN
════════════════════════════════════════════════════════════════════════════

┌─ 🎭 3D PARALLAX EFFECT
│  └─ Implementasi: Mouse event listener + transform translate
│     Efek: Hero visual bergerak mengikuti mouse (smooth depth)
│     File: app.js baris 215-224, styles.css baris 1567-1570
│     HTML: <div data-parallax>

┌─ 🎈 FLOATING CARDS
│  └─ Implementasi: CSS @keyframes animation
│     Durasi: 3-4.5s per cycle (staggered)
│     Delay: 0.2s dan 0.4s per kartu
│     File: styles.css baris 1518-1528 & 1607-1614

┌─ 💡 MOUSE LIGHT
│  └─ Implementasi: Fixed position element + mouse tracking
│     Size: 300x300px dengan blur 40px
│     Color: Radial gradient indigo-violet
│     File: app.js baris 260-271, styles.css baris 1494-1505

┌─ 🔄 3D TILT
│  └─ Implementasi: Calculated rotateX/Y based on mouse position
│     Formula: angleX = (mouseY - cardCenterY) * 5
│     Scale: 1.02 on hover, auto reset on leave
│     File: app.js baris 227-244

┌─ ✨ SERVICE CARD GLOW
│  └─ Implementasi: Pseudo-element ::before + shimmer animation
│     Effects: translateY(-10px), scale(1.02), box-shadow glow
│     Animation: shimmer 2s ease-in-out
│     File: styles.css baris 1531-1593

└─ 📜 SCROLL TRIGGER
   └─ Implementasi: Intersection Observer API
      Event: Detect kartu masuk viewport
      Animation: slideInUp + fade in (0.6s)
      File: app.js baris 276-292, styles.css baris 1596-1605

📞 TROUBLESHOOTING QUICK TIPS
════════════════════════════════════════════════════════════════════════════

❓ Parallax terasa janky?
   → Enable GPU acceleration di browser
   → Check hardware capabilities
   → Disable browser extensions

❓ Effects tidak terlihat?
   → Check browser console untuk errors
   → Verify CSS/JS files loaded
   → Clear browser cache (Ctrl+Shift+Del)

❓ Performance menurun?
   → Disable other heavy scripts
   → Check for console errors
   → Test di fresh browser tab

❓ Mobile tidak bekerja?
   → Normal! Parallax disabled di touch
   → Floating cards masih bekerja
   → Try desktop view untuk full effects
